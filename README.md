# לוח קופסת האוכל

אתר קטן שבו הורים וילדים בונים יחד לוח שבועי לקופסת האוכל, מדפיסים שני עמודים, גוזרים קוביות ומדביקים בסקוטש.

עמוד 1: הלוח, ללמינציה.
עמוד 2: הקוביות לגזירה.

## מה זה מבחינה טכנית

קובץ HTML אחד. אין build, אין תלויות, אין שרת. הכל רץ בדפדפן:

- שמירה אוטומטית ב-`localStorage`
- קישור שיתוף שמקודד את כל המצב ב-hash של ה-URL (base64url עם תמיכה בעברית)
- הדפסה דרך `@media print` בלבד, בלי ספריות PDF. עברית ו-RTL עובדים כי הדפדפן מטפל בהם

## הרצה מקומית

```bash
python3 -m http.server 8000
# פתחו http://localhost:8000
```

או פשוט לפתוח את `index.html` בדפדפן. שיתוף וקישורים עובדים גם ככה.

## פריסה
